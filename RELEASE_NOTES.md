# Release Notes

## Version 1.0.0 (March 17, 2026)

### 🎉 Initial Release

This is the first official release of the QR Code Generator - a professional, feature-rich web application for creating high-quality QR codes.

### ✨ Features

#### 12 QR Code Types
- **URL/Website** - Create QR codes for web links
- **Plain Text** - Generate QR codes for any text content
- **Email** - Pre-filled email with subject and body
- **Phone** - Click-to-call phone numbers
- **SMS** - Pre-filled text messages
- **WhatsApp** - Direct WhatsApp messages
- **WiFi** - Network credentials with encryption support
- **Location** - GPS coordinates with optional labels
- **Calendar Event** - iCal format events
- **App Store** - Links to Google Play, Apple App Store, Microsoft Store, Steam, Amazon
- **Social Media** - 15+ platforms including Facebook, Instagram, Twitter/X, LinkedIn, TikTok, YouTube, and more
- **vCard** - Complete contact information

#### Frame Styles
6 professional frame options for QR codes:
- None (no frame)
- Square Border
- Rounded Corners
- Circle
- Badge (corner accents)
- Scan Me Banner

#### High-Resolution Export
- **1080p Full HD** (1920x1920) - Perfect for web and mobile
- **1440p Quad HD** (2560x2560) - High-resolution displays
- **4K Ultra HD** (3840x3840) - Large format printing
- **8K Ultra HD** (7680x7680) - Professional printing

#### Export Formats
- **PNG** - Raster format with full transparency support
- **SVG** - Scalable vector format

#### Error Correction
Multiple levels to ensure QR code readability:
- Low (7% recovery)
- Medium (15% recovery)
- Quartile (25% recovery)
- High (30% recovery)

#### User Interface
- **Modern Design** - Professional developer tools aesthetic
- **Dark & Light Themes** - Choose your preferred appearance
- **Responsive** - Optimized for desktop, tablet, and mobile
- **Collapsed Sidebar** - Icon-only view with tooltips
- **Real-time Preview** - QR codes generate as you type
- **Single Page App** - Fast, smooth navigation

#### Privacy & Security
- **Client-side Only** - All processing happens in your browser
- **No Data Collection** - Your data never leaves your device
- **No Tracking** - Zero analytics or cookies
- **Zero Vulnerabilities** - Security audited with CodeQL

### 🛠️ Technical Details

#### Technologies Used
- HTML5, CSS3, JavaScript (ES6+)
- Bootstrap 5.3.0 (UI framework)
- Bootstrap Icons 1.11.3
- QRCode.js library
- No build process required

#### Browser Support
- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
- Mobile browsers

### 📦 Installation

Simply clone the repository and open `index.html` in a web browser. No build process or dependencies required.

### 🌐 GitHub Pages

The application is ready for deployment on GitHub Pages. Just enable Pages in your repository settings and point to the root directory.
