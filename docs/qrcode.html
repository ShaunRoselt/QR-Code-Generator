Library Documentation

qrcode.js

`qrcode.js` is a browser-side QR code generator that exposes a global QRCode constructor. In this repository it supports canvas, SVG, and HTML table rendering, automatic QR version sizing, UTF-8 payload handling, and standard QR error correction levels.

  • Works as a plain browser script with no build step.
  • Accepts either a target element or an element id.
  • Supports string shorthand or a full options object.
  • Exposes methods to replace, clear, destroy, and inspect the generated code.
Scope: This page documents the library API exposed by qrcode.js itself. It does not depend on the rest of the app to demonstrate the library.
Global constructor No build step Canvas, SVG, table

Constructor and Options

The library entry point is the global QRCode constructor. Pass a target element or id as the first argument, and either a string payload or an options object as the second argument.

Signature

const qrCode = new QRCode(elementOrId, options);
const shorthand = new QRCode(elementOrId, 'https://example.com');

What the constructor does

  • Resolves the target element.
  • Normalizes margin, error correction, and type options.
  • Selects the canvas, SVG, or table renderer.
  • Generates the QR code immediately when text is provided.
Option Type Default Description
text string none The payload to encode in the QR code.
width number 256 The output width in pixels.
height number 256 The output height in pixels.
margin number 4 The quiet zone around the QR matrix, measured in modules.
border number none Backward-compatible alias for margin.
typeNumber number 0 Exact QR version from 1 to 40. Use 0 for automatic sizing.
minTypeNumber number 0 Minimum QR version to use when automatic sizing is enabled.
colorDark string #000000 The color used for dark modules.
colorLight string #ffffff The color used for the light background.
correctLevel enum or string H One of L, M, Q, or H.
output string canvas Optional renderer override. Supported values are svg and table. Omit it to use canvas mode.
imgStyle string display:block; max-width:100%; Inline CSS applied to the generated image in canvas mode.

Public Methods

The public surface is intentionally small. These are the supported instance methods exposed by the library.

setCode(text)

Replaces the current payload and redraws the QR code. Use this when you want to keep the same instance and update the encoded content.

qrCode.setCode('WIFI:T:WPA;S:QR Demo WiFi;P:scanme123;H:false;;');

makeCode(text)

Legacy alias for setCode(text). It behaves the same way and still redraws the current instance.

qrCode.makeCode('mailto:hello@qrcode.shaunroselt.com?subject=Support');

clear()

Clears the current QR code drawing without removing the generated elements.

qrCode.clear();

destruct()

Removes the generated elements so the original target container can be reused.

qrCode.destruct();

getTypeNumber()

Returns the resolved QR version after generation. This is useful when you let the library size automatically and want to inspect the result.

const version = qrCode.getTypeNumber();

Renderer Modes

The same constructor can render to three outputs. These live examples all use the exact same payload and core settings so you can compare only the renderer differences.

Canvas Output

Canvas is the default mode. This card uses the same payload, size, margin, and error correction level as the SVG and table cards.

new QRCode('canvas-target', { text: sharedRendererPayload, width: 240, height: 240, margin: 4, correctLevel: 'Q' })

SVG Output

Set output: 'svg' when you need vector output instead of canvas rendering. The encoded content is the same as the other two cards.

new QRCode('svg-target', { output: 'svg', text: sharedRendererPayload, width: 240, height: 240, margin: 4, correctLevel: 'Q' })

Table Output

Set output: 'table' to render the QR code as a plain HTML <table>. Each QR module becomes a <td> cell with either the dark or light color, and this card uses the same payload as the canvas and SVG cards.

new QRCode('table-target', { output: 'table', text: sharedRendererPayload, width: 240, height: 240, margin: 4, correctLevel: 'Q' })

Validation and Behavior

The library normalizes options and rejects invalid combinations before drawing. These rules matter when you build wrappers or form-based integrations on top of it.

Validation rules

  • margin must be an integer greater than or equal to 0.
  • typeNumber must be 0 or an integer from 1 to 40.
  • minTypeNumber must be 0 or an integer from 1 to 40.
  • correctLevel must be one of L, M, Q, or H.
  • If an explicit typeNumber is too small for the payload, the library throws an error.

Important implementation details

  • UTF-8 input is supported.
  • A UTF-8 BOM is prefixed when multibyte content is present for better decoder compatibility.
  • Canvas mode automatically calls makeImage() after drawing.
  • This repository also exposes QRCode.CorrectLevelInfo for UI-friendly labels and recovery percentages.

Usage Examples

These examples are intentionally plain and library-focused. They can be copied into any simple HTML page that has loaded qrcode.js.

Basic URL

new QRCode('qrcode', {
  text: 'https://qrcode.shaunroselt.com/docs/',
  width: 300,
  height: 300,
  correctLevel: 'Q'
});

WiFi Payload

const wifiPayload =
  'WIFI:T:WPA;S:QR Demo WiFi;P:scanme123;H:false;;';

new QRCode('qrcode', {
  text: wifiPayload,
  width: 300,
  height: 300,
  correctLevel: QRCode.CorrectLevel.Q
});

vCard Payload

const vcardPayload = [
  'BEGIN:VCARD',
  'VERSION:3.0',
  'FN:Shaun Roselt',
  'N:Roselt;Shaun;;;',
  'EMAIL:hello@qrcode.shaunroselt.com',
  'URL:https://qrcode.shaunroselt.com',
  'END:VCARD'
].join('\n');

new QRCode('qrcode', {
  text: vcardPayload,
  width: 300,
  height: 300,
  correctLevel: 'M'
});

SVG Renderer

new QRCode('qrcode', {
  text: 'https://qrcode.shaunroselt.com',
  width: 240,
  height: 240,
  margin: 2,
  output: 'svg',
  colorDark: '#111111',
  colorLight: '#ffffff'
});
